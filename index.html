SECURITY MODEL

Built around local protection.

01

Random vault keys

Each private space uses its own randomly generated 256-bit master key.

02

Android Keystore

A Keystore-owned AES wrapping key protects vault-key envelopes.

03

AES-GCM encryption

Private files use authenticated encryption rather than plain storage.

04

No cloud vault

The private storage architecture is designed around local app-private storage.

Security claims describe the current application architecture; review the source and release build before relying on an app for highly sensitive information.

FAQ

Good questions.

Is Ginko Player free?

Yes. The site is set up for free APK distribution, with optional support for development.

Does it need internet to play local music?

Local playback is designed to work from music stored on your device.

Where are private files stored?

Private-space files are kept inside app-private storage and encrypted rather than left as ordinary public files.

How do I install the APK?

Download the APK and open it on Android. Android may ask you to allow installation from your browser or file manager.

Why isn't it on Google Play?

Ginko Player is currently distributed directly as an APK while the project is being developed.
