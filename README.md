# Ginko Player — Neo-Brutalist Website

Static website for Ginko Player, inspired by the product-storytelling structure of modern music-app landing pages and rebuilt in Ginko's Neo-Brutalist visual style.

## Included
- Hero / product story
- Music player features
- Private Space explanation
- Detailed How To section
- Three-PIN explanation
- Settings overview
- Support the Creator / Buy Me a Coffee section
- Download CTA
- FAQ
- Privacy Policy page
- Responsive layout

## Before publishing
1. Put the real APK at `download/ginko-player.apk`.
2. Replace `https://github.com/REPLACE_ME` with the real repository URL.
3. Replace `https://www.buymeacoffee.com/REPLACE_ME` with the real Buy Me a Coffee URL.
4. Replace placeholder legal/privacy text with your final policy.
5. Add real app screenshots if desired.

The site is plain HTML/CSS/JS and can be deployed to GitHub Pages, Vercel, Netlify or Cloudflare Pages.
