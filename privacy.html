Local music

Ginko Player is designed as a local Android music player. Music folders selected by the user are scanned locally to build the in-app library.

Private Space

Private Space is stored inside the application's private storage. Files placed into the private areas are encrypted by the application and protected through Android Keystore-backed key material and PIN-derived key protection.

Permissions and folders

Ginko uses user-selected storage folders for music. Removing a folder from Ginko removes it from the app's library configuration; it does not intentionally delete the physical folder.

Analytics and accounts

Ginko Player is not designed around a required user account or cloud music library. This static website may contain external links such as GitHub, LinkedIn, Buy Me a Coffee and VirusTotal; those services have their own policies when you visit them.

Contact

For project questions or bug reports, use the linked GitHub project.
